## 新发现及修复

启动后不打开会话，直接在侧边栏执行“复制为 Markdown”，原实现没有更新剪贴板，也没有提示。打开同一会话后复制成功。

原因有两层：`ensureConversationHistoryLoaded` 在未启用尾部历史加载时默认不读取历史；即使后台已经加载完整历史，没有挂载会话页面的窗口也可能没有前端 transcript 订阅，原生格式化回调仍返回空内容。

新增 `scripts/patch-thread-copy-markdown.js`，注册到 `scripts/patch-all.js`：

- 仅在复制动作中传入 `{force:true}`，加载完整会话以及必要的父会话历史。
- 原生页面回调没有内容时，读取后台完整快照，使用上游完整历史提取器、可见轮次构造器和 Markdown 渲染器导出。保留不支持导出的会话类型限制，不使用有条目上限的上下文接口代替完整导出。
- 空内容、历史不完整、渲染错误和剪贴板写入失败都进入原生错误提示，避免静默结束或复制残缺内容。
- 使用 AST 和语义特征定位，原生辅助函数缺失、重复或动作结构变化时停止补丁；重复运行不修改已修复内容。
