# 2026-10-21 资源管理器菜单修复

修复侧边栏任务右键菜单中“在资源管理器中打开”点击无响应的问题。桌面版本仍为 26.1016.51333，本次修复包保留同日升级的其他补丁。

此后专项排查又修复了未打开会话的 Markdown 复制；包含两项修复的最新产物见 [菜单专项回归记录](2026-10-21-menu-audit.md)。本文保留资源管理器单项修复时的验证结果和包哈希。

## 原因与修复

旧补丁调用通用文件预览函数 `Bq`。新版函数在执行外部打开前读取 `ThreadScope` 的 `clientThreadId`，而侧边栏传入全局作用域，实际抛出 `Missing scope instance`，没有发起系统打开请求。此前对内置文件面板的验证没有覆盖系统资源管理器入口。

`scripts/patch-thread-file-manager-action.js` 现在从原生工作区菜单提取 `onOpenInTarget` 回调，保留工作树准备、最新工作目录解析和错误提示，使用原生 mutation 打开 `fileManager`。直接打开时去除偏好缓存写入和 `persistPreferredTargetPath`，原“打开方式”子菜单的偏好设置行为保持原样。

补丁能够将旧标记迁移为 v2，重复执行不会增加菜单项。无法识别原生回调时明确失败，避免生成只有文案的无效入口。
